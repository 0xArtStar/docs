## 概述

ArtStar 致力于将高门槛、低流动性的艺术品投资，转化为更易参与、更透明、可追踪的链上资产参与方式。

平台围绕艺术品资产发行、用户准入、链上申购、数据同步、积分激励和邀请返佣，构建完整的产品闭环。用户既可以在一级市场参与艺术品份额申购，也可以在后续市场中查看流动性和交易入口。

## 核心价值与解决方案

传统艺术品投资长期存在参与门槛高、流动性差、信息不透明以及合规流程复杂等问题。ArtStar 用产品化的方式解决了这些痛点：

<AccordionGroup>
  <Accordion title="降低参与门槛" icon="arrow-down">
    通过艺术品份额化和链上代币化，用户不需要一次性承担整件艺术品的全部成本，而是可以参与标准化份额
  </Accordion>
  <Accordion title="连接一级发行和二级流通" icon="arrows-rotate">
    平台不仅提供 Launchpad 首发申购，还为后续流动性与交易场景预留承接机制，使资产从“可购买”进一步走向“可流通”
  </Accordion>
  <Accordion title="打通 Web2 合规与 Web3 身份" icon="id-card">
    通过钱包签名登录、KYC 审核、白名单逻辑和链上权限控制，将链下身份要求与链上资产交互整合起来
  </Accordion>
  <Accordion title="引入增长与生态机制" icon="chart-line-up">
    除了资产申购本身，平台还通过积分系统和邀请返佣机制，提升用户留存、活跃和裂变效率
  </Accordion>
</AccordionGroup>

## 核心模块与用户路径

ArtStar 不是单一的 Mint 页面，而是一个综合型平台，当前主要包含以下模块：
艺术品项目展示与资产详情、Launchpad 首发申购、钱包接入与网络守护、KYC 合规认证、用户 Dashboard 与 Wallet、积分系统、邀请返佣系统以及二级市场流动性入口。

<Card title="典型用户的参与路径" icon="route">
  <Steps>

    <Step title="参与申购">在 Launchpad 中使用稳定币完成资产份额申购</Step>
    <Step title="资产管理">在 Wallet 或 Dashboard 中查看持仓与交易记录</Step>
    <Step title="生态互动">通过积分、邀请、返佣等机制持续参与平台生态建设</Step>
    <Step title="流动性交易">在二级市场开放后查看流动性和交易入口，实现资产流转</Step>
